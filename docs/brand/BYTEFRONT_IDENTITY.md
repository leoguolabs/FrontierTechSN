## 视频 ID 动作设计

Byte by Byte：新闻或问题冷开场之后，约 2.5 秒的短 ID。角色先看向纸片，手指抓住边缘，掀起珊瑚色纸片，露出三个相连的点；眼睛随后跟到结果上，栏目名落定。纸片摩擦声与轻短的颤音琴音符对应动作，不加长广告式音乐。当前关键帧表达终态，动作尚未渲染或验收。

Espresso：直接从新闻钩子开始，栏目识别可在约 0.6–0.8 秒的短过渡或首镜角标中完成；不要把整张静态封面长时间占据开头。角色拿起消息卡看一眼，卡片翻面接真实新闻信息。当前竖屏图是造型参考，正式版需按 Shorts 播放控件重新排版；鞋子等非关键信息在底部，不把事实或 CTA 放在那里。

输出动画可沿用原片 24 fps、角色每两帧更新姿态的做法。动作按“预备 → 接触 → 变化 → 收势”组织；纸纹固定，别逐帧闪烁。长片和 Shorts 共用角色、墨线、纸材、音色动机，仅改变节奏和画幅。
