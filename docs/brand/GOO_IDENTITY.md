## 角色的固定特征

- 短而贴头的深棕小卷发，不能换回三根直翘发或高发髻。
- 大号深棕圆眼镜，保留镜桥和镜腿；一侧眼睛较大，另一侧眼睑略低。眼神必须跟着观察目标。
- 宽胖脸、圆钝而向前突出的鼻子、一颗小门牙，短壮身形。保持成人卡通的笨拙感，不画成婴幼儿。
- 芥末黄色连帽衫、深色抽绳、袋鼠口袋，口袋前视右侧有一小块深蓝补丁；深蓝裤、奶油色宽鞋。转面按服装真实空间关系保持补丁位置，不能简单镜像后让补丁换侧。
- 表情可疑惑、侧目、惊讶、得意；这些变化不能改掉鼻形、发型、眼镜结构和牙齿识别点。

当前头像和 ID 是基于附件生成的衍生画稿；生成结果不构成逐像素相同或已经绑定的动画角色。做新镜头时，必须附上原始参考图，并逐镜检查五官、服装和手部接触，不能只在提示词里写角色名。

## 视觉与动作

延续数学 AI 视频所采用的复古印刷卡通方向：暖纸底、棕黑干墨线、平面套色和轻微错版。黄色连帽衫是角色主识别色，深蓝稳定下半身，青绿色用作头像背景或发现提示，珊瑚色用于可操作物体。

| 色彩用途 | 设计目标色 |
| --- | --- |
| 纸底 | `#F6EEDC` |
| 墨线 / 字标 | `#30251F` |
| 黄色连帽衫 | `#E6B43B` |
| 深蓝裤与补丁 | `#263E61` |
| 青绿背景与提示 | `#318D91` |
| 珊瑚按钮 | `#D8664F` |

目标色用于后续制作，不是对位图像素的精确采样。英文使用厚衬线字标，“Oo”中的眼睛呼应圆眼镜；中文独立使用厚重、略不规则的印刷字形，不拼入英文字标。两版都只保留本语言的频道名和角色名，不再加入旧口号、排期、周更承诺或栏目列表。

核心动作是“凑近看 → 用一根手指轻按 → 看见变化”。两张静态 ID 使用同一个按珊瑚按钮的姿势，突出咕仔爱观察、爱动手的性格。后续动态片头可在约 2 秒内完成预备、接触、变化和收势，文字在结果出现时落定；不要让手悬空触发按钮。当前交付是关键帧，未完成上述动画或音效。
