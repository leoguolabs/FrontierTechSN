# 来源和使用范围

此目录是 Bytefront Studio 的个人制作资产。角色定妆和频道 ID 来自用户提供的黄卫衣设计和 FrontierTechSN 品牌记录（Git 3db1204）；reference/anatomy 保留原始说明和生成提示。那些说明中的外链、路径、历史状态以当时的交付为准。Goo 绑定、图集、手部修正、原片证据来自个人独立数学工程，版本见 style.json。模板内对资源 URL 做了带空格目录兼容，对旁白、时间轴、音乐与编码入口做了通用化。

通用绘制基底的原作者与 MIT 许可见 starter/src/rebuild/PROVENANCE.json 和 UPSTREAM-LICENSE.txt。字体、注册名、哈希、OFL 声明见 starter/fonts/manifest.json。第三方组件按各自许可使用。角色、字标、原片、参考截图与本期个人素材按所有者授权范围使用。新例的打板、波形、讲稿和拟音为本次编写；原生语音来自 nr-test 的 Kokoro Eric，模型信息与音频 SHA 在 examples/clap-sync/audio/chapters/slate.json。新题材引用的图片、论据、音频另记来源。

新片封存工具 starter/scripts/reproduction.py 从 FrontierTechSN 内的 Codex Film Studio 子模块原样复制；许可附在同目录 STUDIO-LICENSE.txt。工具复制进每期工程独立运行。

1.1.0 的声音方法来自独立工程 `math-in-ai-goo-tim-suite-20261106` 的实际 Tim 交付和本次用户新指令。原片媒体、提供商音频与逐片 QA 留在该独立工程；本包只提炼通用配置、导入/同步/音量方法。后续默认 1.1 是用户在交付后新增的偏好，不把原生 1.0 长片记为已验证的 1.1 成片。

1.2.0 按 2026-11-08 用户最新要求改为 Tim 提供商原生 1.3 倍，禁止后期倍速。新制作证据保存在独立 `math-in-ai-goo-tim-native130-20261108`；官方参数来源：https://docs.volcengine.com/docs/doubao-voice/task-sub-mission?lang=zh 。旧 1.1 结果保持历史身份。
