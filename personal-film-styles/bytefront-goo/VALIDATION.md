# 方法验证

## 1.3.0 · 2026-11-09

在全新英文工程中，通过 `npm run narrate:en` 导入试听时下载的真实 OpenAI.fm Alloy 原声。11.904 秒原声生成 7.856 秒 48 kHz PCM16 mono WAV。用户确认的参照为 7.85 秒。独立静音检测得到 Goo 后约 0.057 秒、片名后约 0.106 秒。独立 ASR 对齐得分 0.992，排出 5 条字幕和 237 帧测试时间轴。时间轴和词位校验均使用最终 WAV 的 SHA。 另用前置钩子的样本验证片头能在章内定位和处理。

重复运行复用已有原声和交付文件。用模拟 HTTP 响应验证请求、音色、参数和凭据边界。当前环境没有 OpenAI API 密钥，真实合成验证走官方试听页原声导入。新中文工程保留原入口，Eric 打板例从冻结录音重建出 432 帧和 8 条字幕时间轴。

## 1.2.0 · 2026-11-08

使用两段本次实际生成的 Tim 原生 1.3 配音，在新初始化的英文工程中验证导入与对齐；另新建中文配置及历史 Eric 打板工程。机器记录见 [validation-tim-native-1.3.json](validation-tim-native-1.3.json)。

| 检查 | 实际结果 |
|---|---|
| 新英文默认值 | Volcengine Doubao TTS 2.0 / Tim 美式男声；原生 `speech_rate=30`，控件按音调、语速、音量为 `[0,30,0]`；不做后期语速处理 |
| 等时长导入 | A 原声及交付 PCM 均为 40.584 秒 / 1,948,032 采样；B 均为 56.544 秒 / 2,714,112 采样。两者保存的原生 PCM 与交付 PCM 各自字节完全相同，`atempo_passes=0` |
| 错误输入 | 重复导入、错误音色、旧语速回执、标记为后期处理的录音、原文件 SHA 不符均在导入前被拒绝 |
| 独立对齐 | 新 PCM 的独立 ASR、词位与排镜流程通过，生成两章、47 条字幕、2381 帧时间轴；不缩放旧字幕 |
| 配置隔离 | 新中文工程配置未变；指定 `legacy-kokoro-eric` 时仍保留历史原速，不会被 Tim 默认覆盖 |
| 历史示例回归 | 在全新工程安装锁定 Node 依赖，生成 18 秒 / 432 帧 / 960×540 打板预览；PyAV 全量解码声画通过。原生 4K 第 146 帧 SHA 仍为 `3b2b96047e9d81fe2ed329bc02ac1297e8a128b1e15edea05fdcd3ee8e173247`，与 1.0.0 相同；实际查看接触帧 |
| 工具 | 方法包 Python 脚本编译通过；FFmpeg 构建使用共用进程检查及锁。库存清单随本次文件更新 |

本表验证方法包本身。三条数学影片的全量编码、音量平衡、声画同步、浏览器播放和 nr-test 原位替换另见独立工程 `math-in-ai-goo-tim-native130-20261108/REPORT.md`，不将尚未完成的操作写成通过。声音证据包括实际控件、可观察的记录请求、源文件与等时长导入；不声称审查了服务内部闭源实现，也不把 ASR 或浏览器状态当作用户听感认可。

[1.1 历史验证](validation-tim-1.1.md) 保留当时的后期 1.1 处理证据，仅供追溯；该方法已被本次原生 1.3 要求替代。
