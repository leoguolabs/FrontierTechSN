## 1.5.0 · 2026-11-09

通过 Codex Film Studio 的节目名别名新建英文工程，确认 Cedar 配置和 1.4.0 的证据插段入口均随工程复制。在未设置 `OPENAI_API_KEY` 的进程中，从 macOS 钥匙串读取具备 Realtime 请求权限的持久项目密钥，实际调用 `gpt-realtime-2.1-mini` 生成 Cedar。10.35 秒原声按校准节奏生成 7.860 秒 WAV，API 回传转写与同稿一致。字幕对齐得分 0.992，生成 5 条字幕和 237 帧时间轴，音频 SHA 与交付 WAV 一致。失败后复用了已冻结的原声和回执，后续重复运行也复用了现有成品。

已确认试听的 7.85 秒 MP3 单独留档并校验 SHA-256。新中文工程初始化、历史 Eric 录音对齐和 432 帧时间轴通过。14 个旁白与证据插段测试通过。本次验证覆盖实际合成、WAV、字幕与时间轴。

## 1.4.0 · 2026-11-09

## 1.3.0 · 2026-11-09

在全新英文工程中，通过 `npm run narrate:en` 导入试听时下载的真实 OpenAI.fm Alloy 原声。11.904 秒原声生成 7.856 秒 48 kHz PCM16 mono WAV。用户确认的参照为 7.85 秒。独立静音检测得到 Goo 后约 0.057 秒、片名后约 0.106 秒。独立 ASR 对齐得分 0.992，排出 5 条字幕和 237 帧测试时间轴。时间轴和词位校验均使用最终 WAV 的 SHA。 另用前置钩子的样本验证片头能在章内定位和处理。

重复运行复用已有原声和交付文件。用模拟 HTTP 响应验证请求、音色、参数和凭据边界。当前环境没有 OpenAI API 密钥，真实合成验证走官方试听页原声导入。新中文工程保留原入口，Eric 打板例从冻结录音重建出 432 帧和 8 条字幕时间轴。
