# 从实际返工倒推的诊断表

| 看到或听到什么 | 先怎么定位 | 已奏效的做法与复查 |
|---|---|---|
| 头身脱节、角色像纸偶 | 停在转头最大处，单看颈根、帽口和下巴 | 头部倾斜围绕颈根，保留衣领重叠。查连续帧，尤其从惊讶进入托腮的瞬间 |
| 表情与动作单一、动作太慢 | 逐镜写出人物此刻在想什么，量出移动阶段与停留阶段 | 在观察、怀疑、扶镜、托腮、明白之间安排因果。压缩大位移、保留读懂结果的停顿。用户认可 v15 的主要动作速度 |
| 手看似贴反、手腕套在袖子外 | 放大拇指根、掌心纹和短腕，对照人物左右而非素材文件名 | 绑定掌、腕、袖口为一个单元，按局部手别最多镜像一次。托腮、握笔、按键和自然下垂要分别画掌背；把双手同时放进同一张检查图 |
| 握笔时近肘跑到腹部 | 看整个笔画，定位肩—肘—腕的路径，包括刚开始落笔那几帧 | 调桌面和纸的位置，改用近直伸手，肘只略偏离肩到握点的线。v23b 这个方向得到用户认可；最终参考 v23c |
| 远臂遮住一半衣线、袖色不一致 | 暂停在支撑、交叉与托腮；在画面左肩找多余斜黑线 | 两个前景袖子的涂色覆盖躯干旧外线，移除肩部预留圆洞。同一卫衣、袖口共用布色与纹理。v23b 仍有右肩问题，参考 v23c 或 v29 |
| 笔尖悬空、按钮先于手反应 | 标出指尖或握点，在首次接触帧叠放接触标记和道具 | 道具按世界坐标接触点定位，纸面笔触与手同进度，拟音跟同帧。不够得着就移动桌面 |
| 中文拖沓、没精神 | 连听一段完整的问答和一段术语解释，观察拖尾和句间空白 | 普通话男声，口吻像向朋友分享新发现，问题后短停。先用提供商原声参数做连贯表演，按中文真实时长排镜 |
| 英文开场啸叫、部分句突然变快或变慢 | 依次独听原录音、voice、effects、music 和最终 AAC。按句锚回找历史 0:23、0:29、5:43 | 区分原声与混音问题。Alloy 将片头和接句连续合成，单独收紧「I’m Goo」和片名后的空拍，再做整章提速。复听前后文，并按最终 WAV 对齐 |
| AI 被读成 Aye、术语起音太短 | 播原单词和上下句，独立转写作为提示 | 在朗读稿明确术语发音，显示稿保留原文。仍有误读就重录整章并重新对齐 |
| 同一音色的某些章突然很轻 | 比较每章原声与成片响度，不只看整片 −16 LUFS | 本次 Tim 第 2、8 章明显较轻；每章按实测值使用固定增益，平衡到总线前 −24 LUFS，冻结源哈希和增益，保持原时长 |
| 控制台点击合成无结果 | 检查服务开通、可用默认 API Key、按钮 tooltip/cursor、历史记录与新 audio | disabled=false 不等于可用；没有 API Key 时按钮可能只是 cursor:not-allowed。没有真实提交不要反复重试 |
| 已有音频但额度未刷新 | 核对新音频、完整时长、提交文本和历史记录 | 先保存新原声与回执；额度刷新延迟不等于合成失败，不重复扣费生成 |
| 配乐和人声都像一段段拼的 | 听真正连续的一分多钟，打开 MIDI transport 查换镜处是否重启、静音或重新淡入 | 全片一个乐网；各层余音越过镜头与章界。靠音符疏密让推导安静，少用反复淡入。对应 v29 的连续片段与 v27 间隙数据见 baseline |
| 统计都对，观众仍看/听出问题 | 检索 QA 是测过响度、解过码，还是有人在 1× 播放中指出具体问题 | 分开记录测量、画面抽查、连续播放和用户接受。v29 仍记录过规则开关镜头的短暂手臂/标题重叠；新题材把标题移出运动轨迹 |

早期时长目标、中英最终片长、某个笔尖坐标、77 镜、12 次英文合成、92 BPM 都是原片实例。决定可以复用的是组织原声、设置接触和做对照的方式。
